It retains the course outline, examples, and central theme, and rewrites them in modern Java:

    This document is not a comprehensive course. Like the ones from which it is derived, it is intended for people who already know how to program and want to learn the basics of Java. It uses examples: more than two hundred programs (more than three hundred Java files), most of them short, with line-by-line comments.

    1.1. Java from 1995 to 2026

    Java was released by Sun Microsystems in May 1995. It is based on an idea that has been key to its success: the [javac] compiler does not produce machine code but rather an intermediate code—bytecode—stored in [.class] files, which the Java Virtual Machine (the JVM, “Java Virtual Machine”) executes by compiling it on the fly into machine code. A single compiled program can thus run on Windows, Linux, or macOS: “write once, run anywhere.” The Kotlin, Scala, and Groovy languages also produce bytecode and use the same libraries.

    Key milestones:

    • 2006–2007: OpenJDK. Sun released the Java source code under an open-source license (JDK). All current Java distributions are built from OpenJDK;
    • 2010: Oracle acquires Sun and becomes the primary contributor to Java;
    • 2014: Java 8, a pivotal release: lambda expressions, API Stream, new date handling (API). Many programs in production are still written in this style;
    • Since 2017 (Java 9): A new version of Java is released every six months, in March and September. Some versions have long-term support (LTS, “Long-Term Support”): Java 11 (2018), 17 (2021), 21 (2023), and 25 (September 2025), which is used in this document; starting with Java 17, a new version is released every two years. The other versions are supported for only six months; new features often appear first as “previews” before being finalized in a subsequent version;
    • JDK is distributed by several vendors, all of which are based on OpenJDK and are equivalent for our purposes: Oracle, the Eclipse Foundation (Eclipse Temurin, Adoptium project), Microsoft, Amazon (Corretto), and Linux distributions.

    1.3. The Common Thread: Tax Calculation

    The same problem is revisited throughout the document: calculating the income tax for a taxpayer who has only their salary to report. The tax bracket used is the original one (2003 income): it is no longer current, but it suffices for our purpose, which is to write the same application in several different ways. It is implemented in nine versions:

    Version
    Chapter
    Content
    1
    3
    A single program: validated input, calculation, display
    2
    4

    3
    5
    calculation data read from a text file or a JSON file
    4
    6
    A layered architecture ([dao], [metier], [ui]) within a single program
    5
    6

    6

    a [dao] layer that reads data from a MySQL database using JDBC
    7

    8

    9

    Starting with version 5, subsequent versions reuse the layers from version 5 and replace only the layer that has changed: this is the whole point of the layered architecture presented in Chapter 6.

    The small programs are compact source files: a single file named [.java], executed using the command [java Fichier.java] (Chapter 2). Multi-file programs that use only the libraries from JDK are launched in the same way. Programs that require an external library (Jackson, JUnit, Spring, the MySQL driver, Hibernate, Spring Boot) are Maven projects ([pom.xml]).

    All programs in this document were compiled without errors or warnings by the [javac] compiler from JDK 25, using the [-Xlint:all] option that enables all warnings, and were run using the library versions listed in the appendix. The results reproduced in this document are those of these executions. They were obtained using the French language and country settings (fr-FR), as on a French Windows system: formatted floating-point numbers are displayed with a decimal point, and dates are in French. Two notes:

    • the error messages from JDK (exception messages, compiler messages) are in English: JDK does not provide a French translation for them;
    • the examples were run on Linux. For the most part, this makes no difference: Java is cross-platform. The few differences (file paths with / instead of \, terminal commands) are noted where they occur.

    The results of multithreaded, asynchronous, or network programs, as well as the measured execution times, may vary from one run to another: the comments focus on what is reproducible.
